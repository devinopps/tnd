# Проект: «Онлайн-курс «UX/UI-дизайн с нуля»»

## Целевая аудитория
### Primary Audience (основная):
* Возраст: 18–35 лет
* Пол: любой
* Статус: студенты, начинающие специалисты без опыта работы
* Цель: получить практические навыки UX/UI и создать портфолио
* Контекст: ищут краткосрочные онлайн-курсы с практическими заданиями, используют мобильные устройства и десктоп
### Secondary Audience (дополнительная):
* Возраст: 25–40 лет
* Пол: любой
* Статус: работающие специалисты, которые хотят переквалифицироваться
* Цель: получить новый навык для карьерного роста
* Контекст: ищут структурированные онлайн-курсы с возможностью применить навыки на практике
### UX-выводы для дизайна (гипотеза):
* Понятная структура лендинга с ключевой информацией на первом экране
* Яркий CTA сразу на Hero-блоке
* Интерактивные элементы (аккордеон, hover-эффекты) для удержания внимания
* Форма регистрации проста и работает без лишних полей
